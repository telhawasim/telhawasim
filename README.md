<h2 align="center">👨‍💻 About Me</h2>

I'm **Telha Wasim**, a **Senior Mobile Developer & Applied AI Engineer** passionate about building scalable, performant, and intelligent mobile applications.

I specialize in **native iOS development with Swift and SwiftUI**, alongside **cross-platform development with Flutter and Dart**.

My primary focus is designing mobile applications using modern architectures, reusable components, efficient concurrency, and AI-powered capabilities.

- 💼 **Currently:** Senior Software Engineer at **Nextbridge Ltd.**
- 🍎 **iOS:** Swift 6, SwiftUI, UIKit, Swift Concurrency, SwiftData
- 📱 **Cross-Platform:** Flutter, Dart, Firebase, Native Platform Integration
- 🏗️ **Architecture:** Clean Architecture, MVVM, Dependency Injection, Modular Design
- 🧠 **Applied AI:** Core ML, Vision, LLM Integration, RAG, Semantic Search
- 📦 **Open Source:** Developing reusable Swift packages and developer tools
- 🎯 **Engineering Focus:** Performance, Scalability, Maintainability, Security, and User Experience

> "Great mobile experiences are powered by thoughtful architecture, efficient engineering, and meaningful design."

### 📦 SwiftFontKit — Dynamic Typography for Swift

**Reusable Swift package for modern font management.**

Designed to simplify custom font integration into iOS applications.

- Dynamic loading of custom fonts through remote font URLs
- Google Fonts integration
- Automatic font registration and local caching
- SwiftUI and UIKit compatibility
- Reusable Swift Package architecture

**Tech:** `Swift` `SwiftUI` `UIKit` `SPM`

**Status:** ✅ Released — Available on [Swift Package Index](https://swiftpackageindex.com/telhawasim/swift-font-kit)

---

- Core ML and Vision-based classification
- Environmental sensor intelligence
- Observation history with SwiftData
- Native SwiftUI user experience
- Offline-first architecture

**Tech:** `Swift 6` `SwiftUI` `Core ML` `Vision` `SwiftData`

**Status:** 🚧 Under Development
